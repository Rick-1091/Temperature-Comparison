# Jinxi Weather Intro

Opening page for the team’s weather, data, and adaptation project.

## Role in the full website

This page is intentionally a field-based entry point rather than a claim that Jinxi residents use prediction markets or need a particular weather tool. It establishes the project’s central framing:

`weather conditions → place-based activity → local decisions → data signals`

The final section hands users to the team’s later pages on data infrastructure, prediction signals/AI, and comparative adaptation.
